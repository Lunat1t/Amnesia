# Galaxy 3.2.1-alpha.2 — ContextBench

Внутренний исторический Git-бенчмарк из alpha.1 заменён адаптером для независимого [ContextBench](https://github.com/EuniAI/ContextBench). Инструкции по установке и команды см. в README.

Galaxy извлекает файлы из репозитория на базовом коммите задачи, используя только её описание. Внешний пакет ContextBench оценивает предсказания в формате JSONL по собственному набору эталонных контекстов, размеченных людьми. Galaxy выдаёт только предсказания на уровне файлов: фрагменты не содержат надёжных смещений строк, а модель для решения задачи не запускается.

Официальный набор данных и оценщик нужно установить отдельно; локально должны быть доступны репозитории с требуемыми базовыми коммитами. Команда сообщает об отсутствующих репозиториях или коммитах для каждого примера и завершается с ненулевым кодом при частичном сбое.
