# Galaxy 3.1 alpha 1 — Living Graph

В версии 3.1 Galaxy переходит от статического снимка репозитория к модели проекта, которая замечает изменения и оценивает их вероятные последствия.

## Новые возможности

### World Drift

`WorldDriftReport` сравнивает сохранённый снимок с новым сканированием и формирует свидетельства изменений файлов, символов, связей и компонентов. `world-drift` работает только для чтения; `world-sync` обновляет базовую версию и сообщает об учтённых изменениях.

### Future Graph

`FutureGraph` детерминированно распространяет структурные контрфактические последствия. Изменённый узел проходит по обратным связям зависимостей, а прямые зависимости включаются как цели проверки с более низкой уверенностью. Симулятор сообщает масштаб воздействия, тесты, документацию, компоненты, риски и ограничения.

### Memory Reconciler

`MemoryReconciler` проверяет состояние знаний на основе свидетельств. По умолчанию работает в режиме пробного запуска. `--apply` меняет жизненный цикл только по правилам с высокой уверенностью. В конструкции намеренно разделены **обнаружение противоречия** и **разрешение на изменение состояния**.

### Predictive Context Packets

Теперь Context Compiler включает в пакет сведения о влиянии Future Graph и состоянии знаний. Поэтому перед выполнением агенты видят как релевантный контекст, так и текущую степень неопределённости этих сведений.

## Правила безопасности и достоверности

- Future Graph — структурный прогноз, а не гарантия поведения во время выполнения.
- Оценка дрейфа измеряет объём структурных изменений, но не определяет, хорошие они или плохие.
- Конфликты памяти между участниками не переписываются молча при низкой уверенности.
- `brain-reconcile` по умолчанию запускается в пробном режиме.
- Существующие уровни подтверждения Galaxy и детерминированной проверки остаются определяющими.

## Тесты

В версии 3.1 добавлены регрессионные проверки для:

- предварительного просмотра и учёта дрейфа снимка;
- обнаружения изменений символов/файлов;
- распространения масштаба воздействия по обратным связям зависимостей;
- интеграции оценки влияния в пакет контекста;
- аннулирования по хешу исходников репозитория;
- обработки конфликтующих утверждений из доверенных источников в одной и той же позиции.
